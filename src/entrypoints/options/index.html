Backup

See the wiki. Importing replaces all your current data with the file's data. Files from older versions of the extension work too.

YouTube history

Import the video count from a Google Takeout export of your YouTube history, watch-history.json (see the wiki). Only days with no data are imported, since Takeout only gives the number of videos opened.

Online sharing

Other users will only see your watched time, opened time and opened count (more information here). Leave the username blank to be shown as Anonymous.

Danger zone

Deletes all the data saved by this extension. This cannot be undone.
